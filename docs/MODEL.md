# 계산 명세

## 공통

- 모든 자산·수입·생활비의 내부 단위는 **만원**이다.
- 시작 연도는 초기 평가 시점이다. 첫 계산 연도는 시작 연도 + 1이다.
- `retireYears`년까지 저축하고 그 다음 해부터 은퇴 인출한다.
- `allocations[i]`는 **주식 자금 내 VTI 비중**이다. 전체 자산 목표 비중이 아니다.
- `safeAllocations[i]`는 그해 새 자금의 안전자산 비중이며 `null`이면 `safeSavingPct`를 따른다.
- 최초 현금 투자에는 첫해 VTI/SCHD 비율만 적용한다. 해당 현금은 이미 주식에 배정한 금액이다.
- 신규 비중을 바꿔도 기존 주식을 자동으로 재배분하지 않는다.
- 추가 자산은 세후 명목 수령액이다. 수령 연도 말에 들어오며 그해 신규 자금 비율로 투자한다. 성장률·물가로 입금액을 자동 증가시키지 않는다.

## 퇴직금

- `severanceAmount`는 수령 시점 세후 명목금액이며 기본 0이다. IRP 등의 인출 제한과 퇴직소득세는 별도 계산하지 않는다.
- `severanceTiming=retirement`이면 `startYear + retireYears` 연도 말에 수령한다. 즉시 퇴직은 시작 시점에 반영한다. `year`이면 시작 연도부터 계산 마지막 연도 사이를 직접 지정한다.
- 수령 연도 신규 자금 비율로 배분한다. 시작 연도 수령은 첫 신규 투자 비율을 사용하며 초기 자산에 합산한다.
- 퇴직금은 `extraAssets` 배열을 수정하지 않고 별도 항목으로 보관한다. `extraAsset` 결과는 퇴직금과 기타 추가 자산의 합계이며 `severance`는 이 중 퇴직금 부분이다. 표와 CSV에서 포함 관계를 표시한다.
- 연말 수령은 그해 과거 수익·생활비에 소급 반영하지 않는다. 초기 금융자산이나 기타 추가 자산에 이미 포함한 금액은 다시 입력하지 않는다. 연말 수령 후 안전자산 상한·보충 규칙을 적용한다.

## 기본 연간 계산

1. 기초 수량으로 배당, 기초 현금으로 이자를 계산한다.
2. 연간 주가 변동을 반영한다.
3. 저축 중이면 각 ETF 배당을 같은 ETF에 재투자하고 이자를 현금에 남긴 뒤, 연말 저축을 배분한다.
4. 은퇴 중이면 배당·이자를 쓰고 선택한 재원에서 부족분 또는 정액 추가 인출을 꺼낸다.
5. 목표 생활비 방식에서 남는 배당·이자는 현금에 남긴다.
6. 연말 추가 자산을 배분하고 다음 해 주당 배당을 증가시킨다.

`stocks`는 보유 가치 비례 매도, `vtiFirst`는 VTI 우선·SCHD 후순위, `cashFirst`는 현금 우선·이후 주식 비례 매도이다. 요청 금액을 충당하지 못하면 `unfunded`에 남기고 음수 자산을 만들지 않는다.

## 월별 스트레스 테스트

저축 구간은 기존 연간 계산을 공유한다. 은퇴 이후에는 매월 다음 순서로 계산한다.

1. 월초 수량의 연간 주당 배당 ÷ 12, 기초 현금 이자를 계산한다.
2. 해당 월의 VTI/SCHD 주가 수익률을 반영한다.
3. 배당·이자로 생활비를 충당하고 부족분은 현금, 그 다음 주식에서 인출한다.
4. 해당 월 부족 여부·미충당·소진·현금 잔여 개월을 기록한다.
5. 그 시점까지 연초 대비 20% 이상 하락했다면 다음 월부터 주당 배당을 삭감한다. ETF별 연 1회이며, 삭감한 수준에서 이후 성장한다.
6. 연말에 추가 자산을 받은 뒤 보충 규칙을 판단한다.

배당은 실제 분기 지급일 대신 매월 균등 지급을 가정한다. 저축 구간의 배당 삭감은 기존 연간 근사를 유지한다. ‘목표 생활비 부족분’과 ‘기존 정액 추가 인출’은 별도 선택이다. 후자는 목표 생활비가 모자라도 자동 증액하지 않는다.

## 시장 경로

```text
월 로그수익률 = ln(1 + 연간 주가 상승률) / 12
                + 연간 변동성 / sqrt(12) × 상관된 정규 난수
```

주가 상승률은 배당을 제외한 장기 연복리 중심값이다. 산술평균 수익률이 아니다. VTI/SCHD 난수는 설정 상관계수를 공유하며, 같은 난수 번호와 설정은 같은 경로를 만든다. 경로를 한 번 생성해 세 보충 전략에 동일하게 적용한다. 이는 실제 역사 자료의 백테스트가 아니다.

- 기본 `anchored`: 변동 적용 구간의 ETF별 로그 충격 평균을 모든 해당 월에서 차감한다. 최종 ETF 가격은 시작 가격 × `(1 + 설정 주가 상승률)^전체 연수`가 된다. 마지막 달만 강제로 바꾸지 않는다. 은퇴 후만 변동시키면 저축 구간은 고정 수익률을 그대로 유지한다.
- `free`: 충격을 중심화하지 않아 경로별 최종 수익률도 달라진다. 설정값은 로그수익률의 중심이다.
- 고정 모드는 특정 최종 주가를 전제로 한 조건부 경로 비교다. 시장이 반드시 회복한다거나 그 시점을 예측한다는 뜻이 아니다. 최종 주가가 같아도 인출·입금·배당 삭감·안전자산 비중 때문에 기말 보유자산은 다르다. 전략의 회복 판단은 미래 경로를 보지 않는다.
- 기본 선택 선은 반복 계산의 첫 무작위 경로다. 중간 백분위 곡선은 한 경로가 아니므로 월별 주가 지수 그래프와 구분한다. 월별 주가 지수는 배당·입출금 제외 명목 가격이다.
- 초반·후반 급락은 별도의 고정 비교다. 고정 모드에서는 급락 직후 같은 길이의 회복 구간을 두며 로그 회복률을 `2 × 평상 월 로그수익률 − 급락 월 로그수익률`로 정한다. 초반·후반은 같은 월 수익률 묶음의 순서만 다르고 최종 ETF 주가는 설정값과 같다. 회복 기간 확보를 위해 급락 기간은 은퇴 기간의 절반 이하로 제한한다. 급락률 0이면 전 구간 기준선이다. 자유 모드는 기존의 급락 후 평상 수익률만 적용하며 강제 회복이 없다.

## 안전자산 보충

- 목표·최소 잔액 = 다음 12개월의 물가 반영 전체 생활비 합계 × 설정 연수. 배당은 목표에서 차감하지 않는다.
- 보충 없음: 주식을 팔아 현금을 보충하지 않는다. 초과분 상한 규칙은 다른 전략과 동일하게 적용할 수 있다.
- 매년 보충: 연말에 목표까지 주식을 팔아 현금으로 옮긴다.
- 회복 조건부: 최근 1년 가격지수 수익률이 0% 이상이고, 은퇴 이후 관측한 고점 대비 허용 하락률 안이면 목표까지 보충한다. 아니면 최소 잔액까지만 보충한다.
- 회복 지수는 은퇴 시작의 주식 비중으로 고정한 가격지수다. 인출·입금·매도 때문에 회복 판단이 바뀌지 않는다.
- 주식이 부족하면 가능한 만큼만 보충한다. 마지막 계산 연말에는 이후 생활비를 위한 보충을 생략한다.
- 기본 `stressCashCap=true`: 모든 은퇴 연말에 추가 자산·보충을 반영한 현금이 목표를 넘으면 초과분을 해당 연도 주식 내 VTI/SCHD 비율로 투자한다. 목표는 이 경우 연말 상한을 겸하며 물가에 따라 증가한다. 연중 잔액·저축 구간·기본 연간 계산에는 적용하지 않는다. 마지막 계산 연말에도 초과분을 재투자한다.
- 상한 해제 시 기존처럼 초과 현금을 보유한다. 생활비가 0이면 상한도 0이므로 현금은 모두 주식으로 이동한다. 초기·추가 현금을 없애거나 과거 부족분을 소급 충당하지 않는다.
- 보충 매도와 초과분 재투자는 자산 간 이동이며 생활비 수입이나 총자산 증가가 아니다. `cashReinvested`를 표·CSV에 별도로 기록한다.

## 생활비 인출률 상한과 추가 근로 필요액

- 기본 `stressWithdrawalCap=false`로 기존 결과를 유지한다. 켜면 기본 `stressMaxWithdrawalRate=5`를 사용하며 0~100%로 조절할 수 있다. 월별 스트레스 테스트에만 적용한다.
- 매년 시작의 전체 금융자산 × 설정 비율을 그해 생활비 사용 상한으로 정하고 12등분한다. 월별 상한은 그해 중 바뀌지 않는다. 연말 추가 자산·퇴직금은 다음 해 기준 자산부터 포함하며, 초기 수령 퇴직금은 첫해 기준에 포함한다.
- 생활비 방식의 목표액 또는 정액 추가 인출 방식의 계획액(세후 배당·이자 + 예정 추가 인출)을 월 상한까지 감액한다. 배당·이자를 먼저 쓰고 부족한 허용 인출만 현금·주식에서 충당한다. 사용하지 않은 배당·이자는 현금에 남기며 기존 연말 보충·상한 재투자 규칙을 따른다.
- `spendingRate`는 배당·이자를 포함한 실제 생활비 사용 합계 ÷ 연초 금융자산이다. 보충 매도·안전자산 초과분 재투자·자산 수령은 생활비 사용에 포함하지 않는다.
- `capReduction`은 상한 때문에 의도적으로 줄인 계획 생활비다. 허용된 인출도 자산이 없어 지급하지 못했다면 `unfunded`에 따로 남긴다. 상한 감액을 자산 소진으로 해석하지 않는다.
- 원래 목표 생활비와 실제 지급액의 월별 차이가 추가 근로 필요액이다. 연간 합계 `workNeeded`, 월별 물가 환산 합계 `realWorkNeeded`, 필요 개월 `monthsNeedingWork`로 기록한다. 감액뿐 아니라 소진·기존 정액 인출 부족도 포함한다. 실제 근로소득을 가정하거나 자산에 더하지 않는다.
- 선택 경로에 목표 생활비가 부족했던 해를 표의 빨간 배경·문구와 자산/월별 주가/안전자산 차트의 붉은 음영으로 표시한다. 이는 선택 경로의 연도이며 전체 경로의 근로 필요 확률 표시가 아니다. 툴팁의 근로 필요액은 현재 가치 월평균이다.

## 판정과 표시

- 생활비 충당: 모든 은퇴 월에 목표 생활비 이상을 실제 지급했다.
- 요청 인출 미충당: 한 번이라도 요청한 인출을 전부 지급하지 못했다.
- 자산 소진: 한 번이라도 월 중 총자산이 소진되었다. 연말 추가 입금으로 잔액이 회복돼도 이전 소진을 지우지 않는다.
- 연간 평균이 충분해도 특정 월에 부족했다면 생활비 충당 실패다.
- 월평균 수입은 월별 수입의 합 ÷ 12이며, 현재 가치 수입은 각 월의 물가로 환산한 뒤 평균한다.
- 매도·입금·잔액은 명목 연간 합계 또는 연말 잔액이며, 현재 가치 표시 시 해당 연말 물가로 환산한다.
- ‘고점 미회복 중 매도’에는 시장 지수가 고점 아래였을 때의 생활비 매도와 보충 매도가 함께 포함된다.
- 현금 잔여 개월은 배당·이자를 차감하지 않은 전체 월 생활비 기준이다.

## 한계

외환·물가의 확률 충격, 연속 침체의 군집과 두꺼운 꼬리, 매도 세금·거래 비용, 계좌별 인출 제한, 실제 배당 지급일, 근로소득·공적연금은 반영하지 않는다. 모형 내 충당 비율을 실제 은퇴 성공 확률로 해석하지 않는다. 현재 기본 가정의 출처 링크는 화면의 계산 방식에 유지한다.

## 차트 값 확인

- 모든 SVG 차트에 포인터·터치·키보드 시점 선택을 제공한다. 화면 좌표를 SVG 좌표로 바꾸고 가장 가까운 관측 시점을 선택한다. 좌우 화살표·Home·End는 범위 안에서 이동하고 Escape는 표시를 닫는다.
- 자산 차트는 누적 영역 높이가 아닌 VTI·SCHD·안전자산 개별 금액과 총자산을 보여준다. 현금흐름은 만원/월, 주가는 배당·입출금 제외 명목 지수이며, 통화 금액은 현재 구매력 선택을 따른다.
- 툴팁의 월별 날짜는 실제 계산 월이고 연간 관측은 연말로 표시한다. 텍스트는 HTML로 해석하지 않는다. 터치 표시는 손을 떼어도 유지되며 다른 곳 누르기·스크롤·취소로 닫는다.
