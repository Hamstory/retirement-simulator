# 릴리스 확인

자동 검증과 실제 브라우저 검증은 별개다. 수동 확인을 수행한 사람·환경·커밋을 적고 체크한다. 미확인 항목을 통과로 표시하지 않는다.

```text
확인 커밋:
확인 날짜:
확인자:
브라우저 / OS:
파일 또는 실행 URL:
자동 검증 로그 또는 Actions URL:
```

- [ ] `npm test` 통과
- [ ] 월별 계산 변경 시 `npm run test:long` 통과
- [ ] MAN-001 데스크톱·모바일 레이아웃
- [ ] MAN-002 같은 파일 위치에서 실제 브라우저 기록 유지
- [ ] MAN-003 실제 JSON 다운로드·업로드 왕복
- [ ] MAN-004 그래프·현재 구매력 표시
- [ ] MAN-005 키보드 조작·실행 중 취소
- [ ] MAN-006 실제 CSV 다운로드·한글·열 정렬

이번 프로젝트 전환에서는 계산·구조·격리 DOM 자동 검증을 수행한다. 실제 브라우저 수동 케이스는 미실행이다. 단독 파일의 직접 브라우저 조작이 제한된 환경에서는 제한을 명시하고 완료로 표시하지 않는다.
