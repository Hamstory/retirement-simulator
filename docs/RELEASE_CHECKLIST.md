# 계산 명세

## 공통

- 모든 자산·수입·생활비의 내부 단위는 **만원**이다.
- 시작 연도는 초기 평가 시점이다. 첫 계산 연도는 시작 연도 + 1이다.
- `retireYears`년까지 저축하고 그 다음 해부터 은퇴 인출한다.
- `allocations[i]`는 **안전자산을 제외한 ETF 자금 내 VTI 비중**이다. `aorAllocations[i]`·`aoaAllocations[i]`도 같은 기준이며 이들과 추가 종목 비중 합계의 나머지가 SCHD다. 전체 자산 목표 비중이 아니다. 등록 ETF를 한 종목씩 추적하며 ETF 내부 주식·채권을 외부 보유액에 다시 더하지 않는다.
- `safeAllocations[i]`는 그해 새 자금의 안전자산 비중이며 `null`이면 `safeSavingPct`를 따른다.
- 과거 `deployCash` 직접 계산에는 첫해 등록 ETF 비율만 적용한다. 현재 UI는 시작 자금 배분으로 분리하며 아래 호환 규칙을 따른다.
- 신규 비중을 바꿔도 기존 주식을 자동으로 재배분하지 않는다.
- 추가 자산은 세후 명목 수령액이다. 수령 연도 말에 들어오며 그해 신규 자금 비율로 투자한다. 성장률·물가로 입금액을 자동 증가시키지 않는다.

## 종목 관리와 화면 구성

- 기본 다섯 ETF의 설정 필드를 이전 기록과 호환하는 어댑터로 유지하며, 신규 종목은 `customFunds` 배열의 같은 스키마로 처리한다. 종목별 계산 분기를 추가하지 않는다. 추가 종목 최대 12개이며 ID는 고유한 `fund_` 접두 소문자·숫자·밑줄이다.
- 항목은 `id`, `name`, `initial`(만원), `priceGrowth`, `yield`, `dividendGrowth`, `tax`(분배금 유효 세율), `vol`, `crash`(연간 %), `color`, `allocations`(ETF 내 연도별 %, 최대 90년), `severancePct`(퇴직금 전체 %)다. 30~89년 배열은 마지막 비율로 확장한다. 기존 기록에는 빈 배열을 보충한다.
- ETF 내부 배분에서 VTI·AOR·AOA·추가 종목 비율을 지정하고 SCHD는 나머지다. 안전자산을 먼저 배정한 뒤 모든 ETF에 같은 비율 규칙을 적용한다. 최초 현금 이동, 추가 자산·퇴직금, 연간/월간 배당·매도·보충·초과 안전자산 재투자에 등록 종목을 함께 계산한다. 총자산은 모든 등록 ETF 평가액과 현금의 합이며 중복하지 않는다.
- 기본 다섯 종목은 공통 `dividendTax`, 추가 종목은 각 `tax`를 사용한다. 이는 사용자가 정한 유효 세율 가정이며 국내 ETF의 실제 계좌·감액배당·과세 대상별 세금 계산을 대체하지 않는다. 계좌별 세금·환율·매도세는 계산하지 않는다. 원화 기준 평가액과 수익률 가정을 입력한다.
- 모든 추가 종목은 같은 등록 메뉴와 계산 규칙을 사용한다. 신규 종목은 보유액·비중·분배율 0, 가격 상승률 3%·분배금 성장률 0%·변동성 18%·급락률 35%·유효 세율 15.4%의 수정 가능한 비교용 가정으로 시작한다. 실시간 조회값이나 예상 수익률이 아니다. 차트 색상은 48개 프리셋 중 기존 색과 겹치지 않는 색을 우선 무작위 지정한다. 프리셋이나 색상 입력으로 수정하며 기록·JSON·URL에 보존한다.
- 설정 아래 설명은 가격 변화율과 배당 포함 총수익률의 차이, 초기 세전 분배율, 주당 배당 성장, 유효 세율, 변동성과 급락 비교의 차이를 안내한다. 추가 종목 이름으로 상품별 가정·세율을 자동 지정하지 않는다.
- 매도 우선순위는 기존 VTI→SCHD→AOR→AOA→QQQ 이후 추가 종목 등록 순서다. 비례 매도는 전체 등록 ETF 평가액 비중을 사용한다. 종목을 삭제하려면 보유액·모든 연도 비중·별도 퇴직금 비중이 0이어야 하며, 저장된 과거 기록은 수정하지 않는다.
- 등록 종목의 시장 충격도 VTI 공통 요인과 독립 잔차로 생성한다. 기존 네 종목 이후 추가 종목 스트림을 생성하고 마지막에 QQQ 스트림을 생성한다. QQQ 비중 0인 기존 계획의 고정 시드 시장 경로를 보존한다. 최종 연복리 고정과 급락 후 회복은 모든 등록 종목에 각각 적용한다. 시장 회복 판단 지수에는 은퇴 시점 전체 ETF의 고정 가중치를 사용한다.
- 은퇴 계획 / 스트레스 테스트 / 종목 관리 세 탭은 하나의 설정을 공유한다. 탭 변경은 설정·진행 중 계산·완료 결과를 초기화하지 않는다. 비활성 내용은 숨기며, 은퇴 계획 탭에 연도별 투자 비율·계산 내역을 배치한다. 탭은 화살표·Home·End로 선택할 수 있다.
- 이름은 HTML로 해석하지 않으며 CSV에서 따옴표·쉼표·줄바꿈을 이스케이프한다. 관리 정보와 전체 연도 비중도 기존 localStorage 키·기록·JSON에 함께 저장한다.

## 사용 종목과 투자 비율 표시

- `unusedFunds`는 미사용 종목 ID 배열이다. 기본은 초기·연도별 비중이 0인 AOR·AOA이며 신규 등록 종목은 사용 중이다. 사용 중 종목은 0%도 카드·표에서 편집할 수 있고 미사용은 시작 자금·연도별 입력·퇴직금 별도 배분·연도별 계산 내역의 종목 열에서 숨긴다. 사용 상태는 기록·JSON과 함께 저장한다.
- 미사용 처리 전 시작 보유액·최초 현금 투자·90개 연도별 ETF 비율·활성 별도 퇴직금 비율·저장된 시작 비율이 0인지 확인한다. 남아 있으면 전환을 막는다. 사용 상태로 보유액을 계산에서 제거하거나 매도하지 않는다. 직접 입력이나 이전 설정에서 양수 배분이 확인되면 사용 중으로 복원한다. 기존 기록에 사용 상태가 없으면 배분·보유액에서 추론한다. 미사용 필드가 직접 계산 API에 들어와도 보유액을 누락하지 않는다.
- 일괄 설정은 종목별 숫자 카드, SCHD 잔여 비중, 안전자산 비중과 전체 신규 자금 배분 막대를 표시한다. 미리보기는 안전자산을 먼저 제외한 ETF 비율을 전체 금액 기준으로 환산한다. 입력만으로 계획을 바꾸지 않으며 ‘모든 연도에 적용’에서 기존 90개 연도별 비율을 변경한다. 별도 퇴직금 배분과 마지막 저축 연도 안전자산 우선 규칙은 유지한다.
- 연도별 합산 배분과 투자금은 이름·비율·금액을 함께 표시하며 0 항목은 생략한다. 신규 자금 합계 0은 ‘신규 투자 없음’으로 표시하고 비율 열에는 해당 연도의 기준 비율을 참고로 표시한다. 마지막 저축 연도 안전자산 100%는 기존과 같이 우선 표시한다.
- 사용 상태 변경은 금융 수익률 경로를 바꾸지 않는다. 스트레스 입력 식별에서는 `unusedFunds`와 시작 입력 보조값을 제외한다. 실제 시작 보유 금액이 바뀌면 다른 금융 설정처럼 이전 스트레스 결과를 무효화한다.

## 시작 자금 배분

- 종목 관리에서는 개별 시작 금액을 노출하지 않는다. ‘연도별 신규 투자 비율’ 패널의 첫 블록에서 시작 금융자산 총액(만원), 전체 중 안전자산 %, ETF 내부 비율을 설정한다. SCHD는 나머지이며, 시작 배분은 이후 연도별 신규 저축 비율과 독립적이다. 시작 시점 퇴직금은 이 총액에 포함하지 않고 퇴직금 패널에서 별도로 반영한다.
- 입력 변경은 시작 총액 × 안전자산 비율과 시작 총액 × (1−안전자산 비율) × 종목 비율로 기존 초기 평가액 필드를 설정한다. 거래나 미래 리밸런싱을 시뮬레이션하는 기능이 아닌 초기 포트폴리오 가정이다. 이후 연도 저축·기타 추가 자산·퇴직금 배분·세율은 바꾸지 않는다.
- 이전 `deployCash` 설정은 브라우저에서 불러올 때 첫해 ETF 비율로 초기 보유액에 옮기고 같은 금액을 현금에서 차감한 뒤 0으로 바꾼다. 시작 총액과 이후 계산 경로를 유지하며, 이후 첫해 신규 투자 비율이 시작 자산까지 다시 바꾸지 않게 한다. 직접 계산 API의 과거 현금 이동 방식은 호환을 위해 유지한다.
- UI는 기존 초기 평가액에서 총액과 비율을 역산한다. 원래 금액은 입력을 바꾸기 전까지 수정하지 않는다. `startingInputs`는 `{id,value}` 배열이며 `total`(만원), `safe`(전체 %), SCHD 외 종목(ETF 내 %)을 기억한다. 0원 상태에서도 지정 비율을 기록·JSON으로 복원하며, 금액은 0~1,000,000,000만원, 비율 0~100%, ETF 내 명시 비율 합은 100% 이하여야 한다. 이전 설정에는 빈 배열을 보충한다.
- 새 총액·비율이 잘못되면 기존 마지막 유효 결과를 유지하고 입력 오류를 표시한다. 잘못된 입력은 저장·내보내기·스트레스 실행에 사용하지 않는다. 출생·기준 연도 설정의 ‘시작 자금·투자 비율 설정’ 버튼으로 해당 패널에 이동한다.

## 마지막 저축 연도 안전자산 옵션

- 기본 `finalSavingSafeOnly=false`다. 켜면 `retireYears > 0`일 때 `startYear + retireYears` 연도 말 신규 저축·기타 추가 자산의 안전자산 비중을 100%로 적용한다. `annual` 퇴직금도 해당 연말 수령이면 같은 비율을 따른다.
- `custom` 퇴직금 배분, 시작 시점 현금 투자·퇴직금 수령, 기존 보유 ETF와 분배금 재투자는 바꾸지 않는다. 즉시 은퇴는 마지막 저축 연도가 없어 적용하지 않는다. 은퇴 이후 추가 수령도 해당 연도 일반 배분을 따른다.
- 원본 `safeAllocations`·ETF 비중을 수정하지 않는 계산 우선순위다. 옵션 해제 시 원래 비율로 돌아가고 은퇴 시점을 옮기면 적용 연도도 이동한다. 표에는 해당 연도 안전자산 100%를 표시하고 그 입력만 잠근다.
- 일반 계산과 월별 스트레스 테스트의 저축 구간에 같이 적용한다. 은퇴 후 기존 안전자산 보충·상한 규칙은 계속 적용된다. 기존 기록은 해제로 복원하며 설정은 기록·JSON에 함께 저장한다.

## AOR·AOA 가정과 호환

- AOR는 주식/채권 약 60/40, AOA는 약 80/20의 혼합 ETF다. 내부 채권은 별도 현금 완충재가 아니며 필요할 때 ETF 단위로 매도한다.
- 시작 분배율 AOR 2.58%·AOA 2.12%는 2026년 9월 말 12개월 후행 분배율이다. [iShares AOR](https://www.ishares.com/us/products/239756/ishares-growth-allocation-etf), [iShares AOA](https://www.ishares.com/us/products/239729/ishares-core-8020-aggressive-allocation-etf).
- 가격·주당 분배금 연 성장률 기본 3%, 변동성 12%·15%, 연간 급락률 25%·30%는 조절 가능한 비교용 가정이며 수익률 예측이나 역사 자료 추정치가 아니다. 총수익률을 배당 제외 가격 상승률로 넣지 않는다.
- 이전 기록은 새 보유액·연도별/퇴직금 AOR·AOA 비율을 0으로 복원한다. 기존 연도별 VTI 비율과 나머지 SCHD 방식은 유지한다.

## 퇴직금

- `severanceAmount`는 수령 시점 세후 명목금액이며 기본 0이다. IRP 등의 인출 제한과 퇴직소득세는 별도 계산하지 않는다.
- `severanceTiming=retirement`이면 `startYear + retireYears` 연도 말에 수령한다. 즉시 퇴직은 시작 시점에 반영한다. `year`이면 시작 연도부터 계산 마지막 연도 사이를 직접 지정한다.
- 기본 `severanceAllocation=annual`은 수령 연도 신규 자금 비율로 배분한다. 시작 연도 수령은 첫 신규 투자 비율을 사용하며 초기 자산에 합산한다. 기존 기록도 이 방식으로 복원한다.
- `custom`은 퇴직금 전체 금액 기준 `severanceVtiPct`·`severanceAorPct`·`severanceAoaPct`·`severanceSafePct`로 VTI·AOR·AOA·안전자산과 추가 종목의 `severancePct`를 배분하고 나머지를 SCHD로 배분한다. 각각 0~100%, 합계 100% 이하여야 한다. 이 비율은 퇴직금에만 적용하며 저축·기타 추가 자산·최초 현금 투자는 바꾸지 않는다. 비활성 별도 입력값은 연도별 비율 사용 결과에 영향을 주지 않는다.
- 연도별 신규 투자 표의 전체 배분 비율·금액은 저축·기타 추가 자산과 별도 퇴직금 배분을 합산한 결과다. 신규 자금 합계가 0이면 해당 연도의 일반 배분 비율을 표시한다.
- 퇴직금은 `extraAssets` 배열을 수정하지 않고 별도 항목으로 보관한다. `extraAsset` 결과는 퇴직금과 기타 추가 자산의 합계이며 `severance`는 이 중 퇴직금 부분이다. 표와 CSV에서 포함 관계를 표시한다.
- 연말 수령은 그해 과거 수익·생활비에 소급 반영하지 않는다. 초기 금융자산이나 기타 추가 자산에 이미 포함한 금액은 다시 입력하지 않는다. 연말 수령 후 안전자산 상한·보충 규칙을 적용한다. 별도 배분으로 안전자산을 늘려도 스트레스 테스트의 상한을 넘는 금액은 해당 연도 주식 비율로 재투자되므로 기말 보유 비율은 입금 배분 비율과 다를 수 있다.

## 기본 연간 계산

1. 기초 수량으로 배당, 기초 현금으로 이자를 계산한다.
2. 연간 주가 변동을 반영한다.
3. 저축 중이면 각 ETF 배당을 같은 ETF에 재투자하고 이자를 현금에 남긴 뒤, 연말 저축을 배분한다.
4. 은퇴 중이면 배당·이자를 쓰고 선택한 재원에서 부족분 또는 정액 추가 인출을 꺼낸다.
5. 목표 생활비 방식에서 남는 배당·이자는 현금에 남긴다.
6. 연말 추가 자산을 배분하고 다음 해 주당 배당을 증가시킨다.

`stocks`는 보유 가치 비례 매도, `vtiFirst`는 VTI→SCHD→AOR→AOA→QQQ 다음 추가 종목 등록 순서, `cashFirst`는 현금 우선·이후 모든 ETF 비례 매도이다. 요청 금액을 충당하지 못하면 `unfunded`에 남기고 음수 자산을 만들지 않는다.

## 월별 스트레스 테스트

저축 구간은 기존 연간 계산을 공유한다. 은퇴 이후에는 매월 다음 순서로 계산한다.

1. 월초 수량의 연간 주당 배당 ÷ 12, 기초 현금 이자를 계산한다.
2. 해당 월의 등록 ETF 주가 수익률을 반영한다.
3. 배당·이자로 생활비를 충당하고 부족분은 현금, 그 다음 주식에서 인출한다.
4. 해당 월 부족 여부·미충당·소진·현금 잔여 개월을 기록한다.
5. 그 시점까지 연초 대비 20% 이상 하락했다면 다음 월부터 주당 배당을 삭감한다. ETF별 연 1회이며, 삭감한 수준에서 이후 성장한다.
6. 연말에 추가 자산을 받은 뒤 보충 규칙을 판단한다.

배당은 실제 분기 지급일 대신 매월 균등 지급을 가정한다. 저축 구간의 배당 삭감은 기존 연간 근사를 유지한다. ‘목표 생활비 부족분’과 ‘기존 정액 추가 인출’은 별도 선택이다. 후자는 목표 생활비가 모자라도 자동 증액하지 않는다.

## 시장 경로

```text
월 로그수익률 = ln(1 + 연간 주가 상승률) / 12
                + 연간 변동성 / sqrt(12) × 상관된 정규 난수
```

주가 상승률은 배당을 제외한 장기 연복리 중심값이다. 산술평균 수익률이 아니다. VTI를 공통 요인으로 SCHD·AOR·AOA·등록 종목 로그 충격을 `상관 × VTI 난수 + sqrt(1−상관²) × 개별 독립 난수`로 만든다. 설정 상관은 VTI와 각각의 ETF 사이이며, 나머지 ETF끼리는 모형상 그 제곱이다. 같은 난수 번호와 설정은 같은 경로를 만든다. 경로를 한 번 생성해 세 보충 전략에 동일하게 적용한다. 이는 실제 역사 자료의 백테스트가 아니다.

- 기본 `anchored`: 변동 적용 구간의 ETF별 로그 충격 평균을 모든 해당 월에서 차감한다. 최종 ETF 가격은 시작 가격 × `(1 + 설정 주가 상승률)^전체 연수`가 된다. 마지막 달만 강제로 바꾸지 않는다. 은퇴 후만 변동시키면 저축 구간은 고정 수익률을 그대로 유지한다.
- `free`: 충격을 중심화하지 않아 경로별 최종 수익률도 달라진다. 설정값은 로그수익률의 중심이다.
- 고정 모드는 특정 최종 주가를 전제로 한 조건부 경로 비교다. 시장이 반드시 회복한다거나 그 시점을 예측한다는 뜻이 아니다. 최종 주가가 같아도 인출·입금·배당 삭감·안전자산 비중 때문에 기말 보유자산은 다르다. 전략의 회복 판단은 미래 경로를 보지 않는다.
- AOR·AOA도 각각의 변동성·급락률·주가 상승률·분배금 성장률을 적용한다. VTI·SCHD 급락률은 기존 `stressCrash`, AOR·AOA 급락률은 `stressAorCrash`·`stressAoaCrash`다.
- 기본 선택 선은 반복 계산의 첫 무작위 경로다. 중간 백분위 곡선은 한 경로가 아니므로 월별 주가 지수 그래프와 구분한다. 월별 주가 지수는 배당·입출금 제외 명목 가격이다.
- 초반·후반 급락은 별도의 고정 비교다. 고정 모드에서는 급락 직후 같은 길이의 회복 구간을 두며 로그 회복률을 `2 × 평상 월 로그수익률 − 급락 월 로그수익률`로 정한다. 초반·후반은 같은 월 수익률 묶음의 순서만 다르고 최종 ETF 주가는 설정값과 같다. 회복 기간 확보를 위해 급락 기간은 은퇴 기간의 절반 이하로 제한한다. 급락률 0이면 전 구간 기준선이다. 자유 모드는 기존의 급락 후 평상 수익률만 적용하며 강제 회복이 없다.

## 안전자산 보충

- 목표·최소 잔액 = 다음 12개월의 물가 반영 전체 생활비 합계 × 설정 연수. 배당은 목표에서 차감하지 않는다.
- 보충 없음: 주식을 팔아 현금을 보충하지 않는다. 초과분 상한 규칙은 다른 전략과 동일하게 적용할 수 있다.
- 매년 보충: 연말에 목표까지 주식을 팔아 현금으로 옮긴다.
- 회복 조건부: 최근 1년 가격지수 수익률이 0% 이상이고, 은퇴 이후 관측한 고점 대비 허용 하락률 안이면 목표까지 보충한다. 아니면 최소 잔액까지만 보충한다.
- 회복 지수는 은퇴 시작의 ETF 보유가치 비중으로 고정한 가격지수다. 인출·입금·매도 때문에 회복 판단이 바뀌지 않는다.
- 주식이 부족하면 가능한 만큼만 보충한다. 마지막 계산 연말에는 이후 생활비를 위한 보충을 생략한다.
- 기본 `stressCashCap=true`: 모든 은퇴 연말에 추가 자산·보충을 반영한 현금이 목표를 넘으면 초과분을 해당 연도 등록 ETF 비율로 투자한다. 목표는 이 경우 연말 상한을 겸하며 물가에 따라 증가한다. 연중 잔액·저축 구간·기본 연간 계산에는 적용하지 않는다. 마지막 계산 연말에도 초과분을 재투자한다.
- 상한 해제 시 기존처럼 초과 현금을 보유한다. 생활비가 0이면 상한도 0이므로 현금은 모두 주식으로 이동한다. 초기·추가 현금을 없애거나 과거 부족분을 소급 충당하지 않는다.
- 보충 매도와 초과분 재투자는 자산 간 이동이며 생활비 수입이나 총자산 증가가 아니다. `cashReinvested`를 표·CSV에 별도로 기록한다.

## 생활비 인출률 상한과 추가 근로 필요액

- 기본 `stressWithdrawalCap=false`로 기존 결과를 유지한다. 켜면 기본 `stressMaxWithdrawalRate=5`를 사용하며 0~100%로 조절할 수 있다. 월별 스트레스 테스트에만 적용한다.
- 매년 시작의 전체 금융자산 × 설정 비율을 그해 생활비 사용 상한으로 정하고 12등분한다. 월별 상한은 그해 중 바뀌지 않는다. 연말 추가 자산·퇴직금은 다음 해 기준 자산부터 포함하며, 초기 수령 퇴직금은 첫해 기준에 포함한다.
- 생활비 방식의 목표액 또는 정액 추가 인출 방식의 계획액(세후 배당·이자 + 예정 추가 인출)을 월 상한까지 감액한다. 배당·이자를 먼저 쓰고 부족한 허용 인출만 현금·주식에서 충당한다. 사용하지 않은 배당·이자는 현금에 남기며 기존 연말 보충·상한 재투자 규칙을 따른다.
- `spendingRate`는 배당·이자를 포함한 실제 생활비 사용 합계 ÷ 연초 금융자산이다. 보충 매도·안전자산 초과분 재투자·자산 수령은 생활비 사용에 포함하지 않는다.
- `capReduction`은 상한 때문에 의도적으로 줄인 계획 생활비다. 허용된 인출도 자산이 없어 지급하지 못했다면 `unfunded`에 따로 남긴다. 상한 감액을 자산 소진으로 해석하지 않는다.
- 원래 목표 생활비와 실제 지급액의 월별 차이가 추가 근로 필요액이다. 연간 합계 `workNeeded`, 월별 물가 환산 합계 `realWorkNeeded`, 필요 개월 `monthsNeedingWork`로 기록한다. 감액뿐 아니라 소진·기존 정액 인출 부족도 포함한다. 실제 근로소득을 가정하거나 자산에 더하지 않는다.
- 선택 경로에 목표 생활비가 부족했던 해를 표의 빨간 배경·문구와 자산/월별 주가/안전자산 차트의 붉은 음영으로 표시한다. 이는 선택 경로의 연도이며 전체 경로의 근로 필요 확률 표시가 아니다. 툴팁의 근로 필요액은 현재 가치 월평균이다.

## 판정과 표시

- 생활비 충당: 모든 은퇴 월에 목표 생활비 이상을 실제 지급했다.
- 요청 인출 미충당: 한 번이라도 요청한 인출을 전부 지급하지 못했다.
- 자산 소진: 한 번이라도 월 중 총자산이 소진되었다. 연말 추가 입금으로 잔액이 회복돼도 이전 소진을 지우지 않는다.
- 연간 평균이 충분해도 특정 월에 부족했다면 생활비 충당 실패다.
- 월평균 수입은 월별 수입의 합 ÷ 12이며, 현재 가치 수입은 각 월의 물가로 환산한 뒤 평균한다.
- 매도·입금·잔액은 명목 연간 합계 또는 연말 잔액이며, 현재 가치 표시 시 해당 연말 물가로 환산한다.
- ‘고점 미회복 중 매도’에는 시장 지수가 고점 아래였을 때의 생활비 매도와 보충 매도가 함께 포함된다.
- 현금 잔여 개월은 배당·이자를 차감하지 않은 전체 월 생활비 기준이다.

## 한계

외환·물가의 확률 충격, 연속 침체의 군집과 두꺼운 꼬리, 매도 세금·거래 비용, 계좌별 인출 제한, 실제 배당 지급일, 근로소득·공적연금은 반영하지 않는다. 모형 내 충당 비율을 실제 은퇴 성공 확률로 해석하지 않는다. 현재 기본 가정의 출처 링크는 화면의 계산 방식에 유지한다.

## 차트 값 확인

- 모든 SVG 차트에 포인터·터치·키보드 시점 선택을 제공한다. 화면 좌표를 SVG 좌표로 바꾸고 가장 가까운 관측 시점을 선택한다. 좌우 화살표·Home·End는 범위 안에서 이동하고 Escape는 표시를 닫는다.
- 자산 차트는 누적 영역 높이가 아닌 등록 ETF·안전자산 개별 금액과 총자산을 보여준다. 현금흐름은 만원/월, 주가는 배당·입출금 제외 명목 지수이며, 통화 금액은 현재 구매력 선택을 따른다.
- 툴팁의 월별 날짜는 실제 계산 월이고 연간 관측은 연말로 표시한다. 텍스트는 HTML로 해석하지 않는다. 터치 표시는 손을 떼어도 유지되며 다른 곳 누르기·스크롤·취소로 닫는다.


## 자산별 배당 표시

- 각 연간 결과의 `<fundId>NetDividend`는 해당 자산의 당해 연도 세후 배당·분배금이다. 합계는 `netDividend`와 같다. 시작 행은 0이며 화면에는 ‘배당 —’로 표시한다.
- 기본 계산은 기초 수량과 그해 주당 배당으로 계산한다. 저축 중 재투자한 배당도 표시하므로 실제 생활비로 쓴 금액과 다를 수 있다. 월별 은퇴 계산은 각 월초 수량의 세후 배당을 합산하며 매도·배당 삭감 이후 월의 변화도 반영한다.
- 연도별 표는 사용 중인 종목만 표시하고 기말 평가액 아래 작은 숫자로 연간 세후 배당(만원)을 표시한다. 현재 구매력 선택 시 같은 연말 물가로 환산한다. CSV는 기존 열 순서를 유지한 채 모든 등록 종목의 세후 배당 열을 끝에 추가한다.

## 설정 URL

- 현재 유효한 설정 전체를 버전 1 봉투 `{v,c}`에 넣고 URL fragment `#plan=`으로 만든다. 알려진 설정 필드만 내보내며 저장 기록·계산 결과·로컬 파일 경로는 포함하지 않는다. 파일로 연 화면에서는 공개 Pages 주소로 링크를 만든다.
- 긴 연도별 배열은 반복 구간을 압축하고 브라우저 기본 deflate가 있으면 추가 압축한다. 미지원 환경에서는 비압축 형식으로 생성한다. 외부 라이브러리·네트워크 요청은 쓰지 않는다. 압축 링크 읽기에는 브라우저의 DecompressionStream이 필요하다.
- 디코딩 데이터는 262144바이트, 전체 링크는 400000자로 제한한다. 버전·배열 길이·설정 유효성을 검사하며, 잘못된 링크는 현재 설정과 저장 기록을 바꾸지 않는다. 처리 중 사용자가 설정을 바꾸면 덮어쓰지 않는다.
- 링크를 붙여넣거나 열어서 현재 설정을 복원한다. 적용 직전 상태는 되돌리기로 복구할 수 있고 이름 있는 저장 기록은 유지한다. 자동 적용 후 주소의 fragment를 제거한다. URL 자체가 입력값을 담으므로 링크를 받은 사람은 그 내용을 볼 수 있다.


## 은퇴 첫해 현금흐름 요약

- 요약 카드는 기본 연간 계산의 첫 은퇴 연도를 사용한다. 수령한 세후 배당·세후 이자와 실제 지급한 추가 인출을 각각 연간 합계 ÷ 12로 표시하며, 현재 구매력 선택 시 해당 연말 물가로 모두 환산한다. 실제 월별 지급 일정을 뜻하지 않는다.
- 목표 생활비 방식에서 배당·이자가 목표를 초과하면 월 현금흐름 합계에는 생활비에 쓴 부분만 포함한다. 구성에는 전체 수령액을 표시하고, 안전자산에 남긴 초과분을 별도 안내한다. 요청 인출 중 미충당 금액은 실제 추가 인출에 넣지 않는다.


## 저장 기록 덮어쓰기

- 저장 기록 목록의 덮어쓰기는 선택한 기록의 ID·이름·목록 위치를 유지하고 현재 유효 설정의 독립된 사본과 새 저장 시각을 저장한다. 새 기록을 추가하거나 현재 입력을 변경하지 않는다.
- 성공 안내의 되돌리기는 덮어쓰기 전 기록과 시각을 복원한다. 다른 기록과 현재 입력은 유지한다. 이후 기록이 다시 변경되었다면 오래된 되돌리기로 덮어쓰지 않는다. 입력 오류·저장 실패 시 원래 기록을 유지한다.


## 기본 QQQ와 데이터 기준

- QQQ는 Nasdaq-100을 추종하는 기본 ETF이며 추가 종목 12개 한도를 사용하지 않는다. 초기 보유액·연도별·퇴직금 비중은 0이고 기본은 미사용이다. 종목 관리에서 사용 중으로 전환해 비중을 설정한다. 기존에 별도 등록한 QQQ는 자동 병합하거나 삭제하지 않는다.
- 시작 세전 분배율 0.42%는 [Invesco 공식 상품 페이지](https://www.invesco.com/us/en/financial-products/etfs/invesco-qqq-trust-series-1.html)의 2026-10-15 기준 12개월 분배율이다. SEC 30일 수익률과 구분하며, 화면에 출처와 날짜를 표시한다. 오프라인 기본값이므로 실시간 갱신하지 않는다.
- 배당 제외 주가 상승률 3%와 주당 분배금 성장률 3%는 기존 기본 ETF와 같은 비교용 장기 가정이다. 변동성 25%·급락률 45%도 조절 가능한 위험 시나리오 가정이며 역사 자료에서 추정한 값이나 수익률 예측이 아니다. 과거 높은 총수익률을 배당 제외 가격 성장에 그대로 넣지 않는다. QQQ에도 기본 ETF 공통 배당 세율을 적용하며 환율·계좌별 세금은 별도 모형화하지 않는다.
- QQQ의 초기/신규/추가/퇴직금 배분·배당·매도·보충·안전자산 초과 재투자는 같은 공통 계산을 사용한다. VTI 우선 매도는 기존 네 종목 다음 QQQ, 이후 추가 종목 등록 순서다.
- 과거 기록·JSON·설정 링크에 QQQ 필드가 없으면 보유액과 비중 0으로 보충하고 미사용으로 둔다. 기존 현금·배분·기록은 변경하지 않는다. 양수 보유액·비중이 있으면 기존 사용 보호 규칙을 따른다.

QQQ 경로 호환 검증은 과거 공개 엔진의 가상 설정 표본을 절대 오차 1e-12 이내로 비교하고, 이후 난수 상태는 정확하게 비교한다. 운영체제/CPU 수학 함수의 미세한 차이를 경로 변경으로 잘못 판정하지 않도록 한다.
